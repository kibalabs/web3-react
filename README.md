# @kibalabs/web3-react

**Moved to `@kibalabs/core/web3`.** This package is no longer maintained.

```bash
npm uninstall @kibalabs/web3-react
npm install @kibalabs/core
```

Then replace imports of `@kibalabs/web3-react` with `@kibalabs/core/web3`. Its libraries (`ethers`, `@reown/appkit`, `@reown/appkit-adapter-ethers`, `@base-org/account`, `@safe-global/safe-apps-sdk`, `@safe-global/safe-apps-provider`, `react`, `react-dom`, `react-router`) are optional peer dependencies there, so add them to your app's dependencies.
